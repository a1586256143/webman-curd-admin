# AI 开发技能（webman-curd-admin-dev）

插件自带一个 **WorkBuddy 技能（skill）**，把日常开发的高频命令、命名规则、DSL 速记、宿主同步流程、
必踩坑打包成一份 AI 助手能直接用的「操作手册」。装上它之后，你只要用**自然语言**描述要做什么，
助手就会按插件的正确姿势把活干完 —— 不用自己记命令、不用踩那些会卡半天的坑。

> 这份文档是给**人**看的「怎么用」；具体的命令与选项清单在技能文件里（AI 助手读的那份）。

---

## 1. 它能帮你干啥

| 你想做 | 直接说（举例） |
|---|---|
| 给一张表生成后台管理页 | 「给 `hf_goods` 表生成一个商品管理页，标题『商品管理』」 |
| 给已有页面加操作按钮 | 「给商品页加个『审核』行级按钮」「加个『批量上架』批量按钮」 |
| 给已有页面加 Excel 导入 | 「给商品页加个 Excel 导入」 |
| 生成 / 轮换接口加密密钥 | 「重新生成一下接口加密密钥」 |
| 理解某个 Grid DSL 怎么写 | 「`grid()->column()` 怎么显示图片」 |
| 把改动同步到运行中的宿主 | 「把刚才的改动同步到宿主并重启」 |

技能覆盖的完整命令：`make:curd` / `make:curd-action` / `make:curd-import` / `curd:crypto-key`，
外加 Grid DSL 速记、宿主同步（rsync + restart）、以及那几条「必踩坑」。

---

## 2. 技能在哪

技能有两份，内容一致（改一处要同步另一处）：

| 位置 | 用途 |
|---|---|
| `<插件仓库>/.workbuddy-ai/skills/webman-curd-admin-dev/SKILL.md` | 插件仓库自身用；把仓库打开为工作区时自动加载 |
| `<插件仓库>/plugin/curd/skills/webman-curd-admin-dev/SKILL.md` | **随 composer 包分发**；`curd:publish-skill` 用它发布到宿主项目根 |

它是**项目级技能**，跟随插件仓库一起提交（`.gitignore` 不会忽略它），团队共用、随仓库演进。

---

## 3. 怎么用

1. **把插件仓库作为 WorkBuddy 的工作区打开**
   （即打开 `/Users/colin/Public/www/company/webman-curd-admin` 这个目录）。
   项目级技能会在工作区里自动被发现，出现在可用技能列表里。
2. **像平常聊天一样下指令**即可。例如：
   - 「给 `hf_goods` 表生成 CURD 页面，标题『商品管理』，并注册路由」
   - 「给商品管理页加一个『审核』行级操作按钮」
   - 「给商品管理页加一个 Excel 导入」
   - 「重新生成接口加密密钥并重启宿主」
3. 助手加载技能后，会：
   - 在**宿主根目录**执行正确的命令（不会跑错目录）；
   - 自动处理命名推导、幂等、备份 + `php -l` 自检；
   - 需要的话把改动 **rsync 同步到真实宿主并 restart**；
   - 两个仓库分别提交。

不需要记任何命令，也不需要手动调技能 —— 提到上面那些事，助手会自行判断并加载。

### 其他 AI 工具也能用（Cursor / Codex / Claude Code …）

技能文件本身是**纯 Markdown + YAML 头**，内容不锁定任何工具；差别只在「自动加载」：

- **WorkBuddy AI**：把插件仓库作为工作区打开 → 自动发现 `.workbuddy-ai/skills/` 下的技能并加载。
- **其他 AI 编码工具**：读仓库根的 [`AGENTS.md`](../AGENTS.md)（Codex / Cursor / Gemini CLI 等的通用约定文件），
  里面已经浓缩了同样的命令、同步流程与必踩坑，并指向技能全文。Claude Code 通过根目录 `CLAUDE.md`（`@AGENTS.md`）同样能读到。
- **人**：直接看 `.workbuddy-ai/skills/webman-curd-admin-dev/SKILL.md` 或 `AGENTS.md` 就能照着做。

> 一句话：**手册是通用的，自动加载才是工具差异**。换任何 AI 工具，让它先读 `AGENTS.md` 即可。

## 7. 引入到自己的项目（composer 场景）

如果本插件是作为 **composer 包**被你的项目 `require` 的，技能默认**不会被扫到**：

- 技能文件随包落在 `vendor/amcolin/webman-curd-admin/` 与 `plugin/curd/skills/`；
- 而 AI 工具只扫**工作区根目录**：WorkBuddy 看 `{项目根}/.workbuddy-ai/skills/`，
  Cursor / Codex 看 `{项目根}/AGENTS.md`；
- 包根目录的 `.workbuddy-ai/`、`AGENTS.md` 不会被 `support\Plugin` 拷到宿主，所以自然扫不到。

**一条命令发布到项目根**（在宿主根目录执行）：

```bash
php webman curd:publish-skill
```

它会：

1. 复制技能到 `{项目根}/.workbuddy-ai/skills/webman-curd-admin-dev/SKILL.md`；
2. 在 `{项目根}/AGENTS.md` 写入/更新一段托管块（保留你已有的内容，幂等）。

之后用 WorkBuddy 打开项目根，或让 Cursor / Codex 读 `AGENTS.md`，即可使用。
升级插件后加 `--force` 重跑一次，同步最新手册：

```bash
php webman curd:publish-skill --force
```
