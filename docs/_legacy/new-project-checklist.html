webman-curd-admin 新项目接入流程表

默认单库模式：认证表与业务表放同一库；Web 安装向导 /app/crud-installer 为推荐安装方式

✓检查项要求 / 命令说明

☐Composercomposer -V装插件与依赖

P1创建项目骨架

✓步骤命令 / 操作产物 / 验收点
☐1.1 初始化 webman
composer create-project workerman/webman my-app
cd my-app
标准骨架（config/ app/ runtime/ 自带 support\Plugin 钩子）
☐1.2 确认端口改 config/process.php 的 'listen' => 'http://0.0.0.0:8787' 行⚠️ webman 2.x 端口在此文件，不在 config/server.php

P2引入插件（composer）

✓步骤命令 / 操作产物 / 验收点
☐2.1 配置源 + 安装
composer config repositories.crud vcs "https://gitee.com/colingit/webman-curd-admin.git"
composer require amcolin/webman-curd-admin:^1.0
自动完成四件事：① 拉齐依赖 webman/database + webman/redis + casbin/casbin + vlucas/phpdotenv；② 官方插件机制自动拷贝 plugin/crud；③ 生成 config/database.php（env 驱动，含 mysql + mysql_business）；④ 生成 config/crud.php（集中配置入口）
☐2.2 audit 红字处理
# 不想看到 "Failed to audit installed packages."：
# 用包内 wrapper（仅对 require/update/install 等子命令自动 --no-audit）
alias composer='/path/to/webman-curd-admin/scripts/composer.sh'
composer require amcolin/webman-curd-admin:^1.0
红字是 packagist.org 不可达的尾部告警（exit 0 不影响安装）；wrapper 或 alias 一劳永逸
☐2.3 校验ls plugin/crud config/database.php config/crud.phpplugin/crud 含 app/ config/ public/ api/ install.php；config 两文件已生成
兜底（极少见自动拷贝未触发）：composer dump-autoload && composer update amcolin/webman-curd-admin，或 cp -r vendor/amcolin/webman-curd-admin/plugin/crud plugin/crud。

P3配置数据库（config/crud.php 优先）

✓方式操作说明
☐方式一【推荐】交给向导启动后访问 /app/crud-installer 填表，DB 信息自动写入 .env（按键合并，绝不覆盖原内容）+ config/crud.php 的 database 段无需手改任何配置文件；库不存在自动创建
☐方式二 手动编辑编辑自动生成的 config/crud.php：
'database' => [
    'host'     => '127.0.0.1',
    'port'     => '3306',
    'username' => 'root',
    'password' => '你的密码',
    'admin_db'    => 'my_admin',   // 认证/管理面库
    'business_db' => 'my_admin',   // 单库=同名；分库填其它库名
],
优先级：config/crud.php database > .env DB_* > 默认值。老宿主仍可用 .env
⚠️ 单库模式：业务库连接 mysql_business 与 mysql 指向同一库（business_db 留空自动回退认证库名）；想分库改 business_db 即可。不要 cp env.example .env 整体覆盖宿主 .env（v1.0.5 起已不需要）。

P4安装（Web 向导推荐 / CLI 备选）

✓模式命令 / 操作说明
☐先启动服务
php start.php start
Web 向导需要服务在线
☐4A【推荐】Web 向导浏览器打开 http://host:port/app/crud-installer，填：
· 数据库（主机/端口/库名/账号/密码，库不存在自动建）
· 管理员账号密码（自定义初始管理员，非固定 admin/admin123）		自动：DB 写 .env + config/crud.php → 子进程执行 install.php → 页面实时进度（建库/建表/种子/密钥逐条 ✓）。只预置【超级管理员】角色，其它角色登录后台按需新增。安装成功写 config/crud-installed.lock，向导自动失效；重装=删锁+清库
☐4A ⚠️ 完成后重启
php start.php restart
必须执行：worker 配置在启动时固化，不重启会用旧（空）密码连库 → 心跳报 1045 Access denied
☐4B【命令行】等价流程
# 2a) 配置 DB（config/crud.php 或 .env）
# 2b) 一键安装（幂等、自动建库、自定义管理员）
php plugin/crud/install.php --admin-user=admin --admin-pass=你的密码
# 可选：--progress-file=runtime/i.log  --business-sql=xxx
与向导等价；8 表 + 种子（仅 admin 角色 + 6 菜单）+ RSA 密钥；重复执行全 SKIP

P6业务开发（写控制器即跑）

✓步骤操作说明
☐6.1 建业务表写 install-business.sql（--SPLIT-- 分隔、全 IF NOT EXISTS），重跑 P4B 命令结构变更走增量 SQL 或 migrate.php（migrations/ 目录）
☐6.2 建模型app/model/Xxx.php extends plugin\crud\app\model\BaseModelModelRegistry 自动扫描 app/model/
☐6.3 写控制器
namespace app\controller\api;
use plugin\crud\app\controller\base\BaseCrudController;
class GoodsController extends BaseCrudController {
    protected string $modelClass = \app\model\Goods::class;
    protected string $title = '商品管理';
}
一行继承即得整套 CRUD + 查询 + 权限
☐6.4 登记菜单/权限后台「菜单管理」加节点 + casbin 规则（或追加进 install-business.sql 种子）前端即见即用（内置 dist 已含前端）

P7生产部署（简要）

✓项操作说明
☐守护进程supervisor / systemd 托管 php start.php start禁用 -d 裸跑；完整配置见 docs/deploy.md
☐Nginx 反代/ → webman；/app/crud/ 同域透传SPA 与 API 同域免 CORS；反代端口与 config/process.php 一致
☐安全收紧admin_require_permission=true（config/crud.php）；登录后立即改管理员密码初始管理员由安装向导自定义，无固定 admin123
☐密钥管理config/keys/ 不入 git、不进发布 zip；独立挂载并备份仅 API_ENCRYPT=true 时使用

P8升级与维护

✓场景操作风险 / 注意
☐插件升级./scripts/composer.sh update amcolin/webman-curd-admin 或 composer update amcolin/webman-curd-admin⚠️ 项目内 plugin/crud 是拷贝件且升级不会自动更新（保护本地改动）——需要同步新插件文件时执行 bash scripts/sync-plugin.sh（先备份再整体重拷）
☐升级前检查bash scripts/check-plugin-overrides.sh <项目根>0=无本地改动；1=有改动需先处理再升级
☐发版包仓库 git tag vX.Y.Z → push当前 tags：v1.0.x（用 ^1.0 约束直接拉最新）

⚠️ 高频坑位速查（v1.0.8 已全部修复/有解）

现象原因解法
登录后 Class "support\Redis" not found旧版（≤v1.0.7）未拉 webman/redis升级到 ^1.0（v1.0.8 自动 require webman/redis）；Redis 不可用时已 try/catch 降级直查 DB
运行期 SQLSTATE[HY000] [1045] Access denied ... using password: NOworker 启动时 .env 已 putenv 固化，向导写文件后运行时 env() 仍是空向导已同时写 config/crud.php database 段；装完执行 php start.php restart
Failed to audit installed packages.composer audit 硬编码访问 packagist.org，国内不可达exit 0 无影响；alias 到 scripts/composer.sh 后不再出现
「roles 种子里怎么没有运营/财务？」v1.0.8 起默认只种超级管理员后台「角色管理」按需新增，再授 casbin 权限

流程全景

P0 环境检查→ P1 骨架→ P2 composer 引入→ P3 配置 DB→ P4 向导安装 + restart→ P5 登录验收→ P6 业务开发→ P7 生产部署→ P8 升级维护
标注 ☐ 处可逐项勾选；P0–P5 为必经主链路（约 10 分钟跑通到登录页），P6–P8 按需。完整细节见包内 README.md 与 docs/deploy.md。
